# 🎃 Haunted Crew — a Halloween party theme for Kiro Crew

> **You have `haunted-crew-theme.zip`, the version that works everywhere.**
> The animated welcome screen and the "Behind the chat" block party listed
> below are only in `haunted-crew-theme-full.zip` (Kiro Crew 0.11 or newer).

The Crew mates dress up for Halloween and throw a party in your dashboard.

## Install

**There are two zips:**

- **`haunted-crew-theme.zip`** works on every Kiro Crew version, including the
  current Stable release. It leaves out the animated welcome screen and the
  background block party (moon, bats, pumpkin patch).
- **`haunted-crew-theme-full.zip`** adds those two. It needs Kiro Crew 0.11 or
  newer, which is currently only the RC or Nightly build. On older versions it
  won't install.

Not sure? Use `haunted-crew-theme.zip`.

1. Unzip the zip you picked. You get a folder named `haunted-crew/`.
2. In Kiro Crew, open **Settings → Display → Theme → Install Theme**.
3. Choose **Local folder**, paste the full path to the `haunted-crew` folder
   (the one that holds `theme.json`), and press **Install**.
4. Pick **🎃 Haunted Crew** in the theme list. It works in dark and light mode.
5. When asked, choose **Enable experience**. This turns on the animations,
   sounds and the Captain Boo persona together. (**Keep colors only** switches
   you back to your previous theme rather than keeping Haunted Crew's colors.)

**Want the visuals without the persona?** Delete `persona.md` from the folder
before you install. Everything else keeps working, and the persona is skipped.
Sounds can be turned off any time with the speaker button in the bottom-right
corner.

To update, install the new folder again. It replaces the old copy.

Getting the full path: most file managers can copy it for you (look for
**Copy path** or **Copy as path** when you right-click the folder), or you can
copy it from the file manager's address bar.

If the install says it found an unexpected file, your system probably added a
hidden file (such as `.DS_Store` or `Thumbs.db`) while you browsed the folder.
Unzip a fresh copy and install that, without opening the folders inside it.

## What's inside

| Part | What it does |
|---|---|
| Costumes | The Crew mate ghost as witch, vampire, black cat, mummy and Frankenstein, each standing, floating and flying, with or without a treat |
| Palette (dark) | Candy night: grape purple, pumpkin orange, lime, lavender, pink |
| Palette (light) | Pumpkin patch afternoon: warm cream, burnt orange, plum |
| Fonts | Fredoka (UI), Space Mono (code), Griffy (primary buttons) |
| Branding | Witch Crew mate on the purple Crew tile, pumpkin-tile favicon, animated welcome, wordmark |
| Loader | Four pieces of candy (candy corn, a candy bar, a twist, taffy) cycle beside "Thinking..." |
| Behind the chat | A block party: a glowing full moon, string lights, a flying witch, friendly bats that loop-the-loop, sleepy bats hanging from the lights, pumpkins at both edges holding trick/treat signs ("TREAT! green CI", "TRICK! it is DNS"), and trick-or-treaters who stop for candy |
| Dangle | A Crew mate drops on a web thread, swings upside down and says hi; a new costume each time |
| BOO! | Costumed Crew mates pop in around a big BOO! with candy confetti: when you switch to the theme, then again every 30 minutes |
| After 90 s idle | A random Crew mate pops up and says something silly |
| Top bar | Four gentle skits: trick-or-treat hop, pumpkin roll, bat chase, conga line |
| Sounds | Sparkly "ta-da", "byeee", cauldron bloop, ding-dong, music-box chime, and a cartoon wah-wah (no background music) |
| Styling | Glowing composer, candy-corn code blocks, bouncy buttons |
| Persona | Captain Boo: friendly ghost captain who calls the agents "the crew" |

Overlays are click-through. They stay off under reduced motion. Sounds respect
the mute button. The persona never touches code, commands or security
warnings, and it drops the act when asked.
